## Smoke Filter Rationale

New rows (smokeOrder 21-23) are `tier: "must-pass"`. Adding them unfiltered to the `smoke` command would break §22 behavior: any failure would stop the suite early. Minimum filtering change: `SMOKE_ROWS.filter(r => r.smokeOrder <= 20)` for smoke mode. RC mode receives all rows (unfiltered). Individual row execution via `runner row <ID>` uses `rowById()` which scans all of SMOKE_ROWS.
